## Identitas Peserta

**Nama:** Agung Yonisa Putra
**Jurusan:** D4-Teknik Informatika

## Deskripsi Repository

Repository ini dibuat sebagai dokumentasi kegiatan workshop **"Building with AI, Managing Change with GitHub"**.

Repository ini digunakan untuk menyimpan materi workshop, catatan pembelajaran, dokumentasi kegiatan, serta hasil pembelajaran selama mengikuti workshop.

## Tujuan

Repository ini dibuat untuk:

1. Mendokumentasikan kegiatan workshop Day 1.
2. Menyimpan materi dan catatan pembelajaran secara terstruktur.
3. Menerapkan penggunaan Git dan GitHub.
4. Memahami dasar version control.
5. Mendokumentasikan proses pembelajaran mengenai AI dan GitHub.

## Materi Workshop

Materi yang dipelajari dalam workshop meliputi:

- Prompt Engineering
- Pengertian dan struktur prompt
- Context dalam penggunaan AI
- Git dan GitHub
- Git Workflow
- Repository dan Staging Area
- Git Commands
- Git Setup
- VS Code Setup
- Commit dan Push
- Student Task Planner

## Isi Repository

Repository ini terdiri dari:

- `README.md` — informasi utama mengenai repository dan kegiatan workshop.
- `materi-workshop.md` — rangkuman materi yang disampaikan selama workshop.
- `catatan-pembelajaran.md` — catatan dan pengetahuan yang diperoleh.
- `dokumentasi-kegiatan.md` — dokumentasi rangkaian kegiatan workshop.

## Kesimpulan

Kegiatan workshop memberikan pemahaman mengenai penggunaan AI dalam proses pengembangan project serta penggunaan Git dan GitHub untuk mengelola perubahan project secara terstruktur.
