# Dokumentasi Kegiatan Workshop

## Building with AI, Managing Change with GitHub - Day 1

### 1. Nama Kegiatan

**Building with AI, Managing Change with GitHub**

### 2. Hari/Tanggal

**Day 1 Workshop**

### 3. Peserta

**Nama:** Agung Yonisa Putra

### 4. Deskripsi Kegiatan

Kegiatan workshop Day 1 membahas pemanfaatan Artificial Intelligence (AI) serta penggunaan Git dan GitHub dalam proses pengembangan dan pengelolaan project.

Peserta mempelajari cara membuat prompt yang efektif, memahami pentingnya context dalam penggunaan AI, serta mempraktikkan penggunaan Git dan GitHub untuk menyimpan dan mengelola perubahan project.

### 5. Materi yang Disampaikan

Materi yang disampaikan selama kegiatan meliputi:

- Prompt Engineering.
- Struktur prompt.
- Context dalam penggunaan AI.
- Pengenalan Git.
- Pengenalan GitHub.
- Git Workflow.
- Working Directory.
- Staging Area.
- Repository.
- Git Commands.
- Git Setup.
- VS Code Setup.
- Commit dan Push.
- SSH Key.
- Student Task Planner.

### 6. Praktik yang Dilakukan

Dalam kegiatan workshop, peserta melakukan beberapa praktik, antara lain:

1. Membuat dan memahami prompt untuk AI.
2. Mengenal penggunaan Git sebagai version control.
3. Membuat repository GitHub.
4. Mengatur repository agar dapat diakses secara Public.
5. Membuat dan mengelola file dalam repository.
6. Melakukan commit terhadap perubahan.
7. Menghubungkan project dengan GitHub.
8. Melakukan push perubahan ke repository.
9. Mendokumentasikan hasil kegiatan menggunakan file Markdown.

### 7. Poin Penting yang Dipelajari

Beberapa poin penting yang diperoleh dari kegiatan workshop adalah:

- Prompt yang jelas dapat membantu AI menghasilkan output yang lebih sesuai.
- Context merupakan bagian penting dalam memberikan instruksi kepada AI.
- Git digunakan untuk mengelola versi dan perubahan project.
- GitHub digunakan untuk menyimpan repository secara online.
- Commit digunakan untuk menyimpan perubahan.
- Push digunakan untuk mengirim perubahan ke GitHub.
- Repository dapat digunakan sebagai tempat dokumentasi project.
- File Markdown dapat digunakan untuk menyusun dokumentasi secara terstruktur.
