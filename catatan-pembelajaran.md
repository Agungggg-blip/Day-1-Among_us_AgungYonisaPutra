# Catatan Pembelajaran Workshop

## Building with AI, Managing Change with GitHub

### 1. Prompt harus dibuat dengan jelas

Salah satu hal yang dipelajari adalah pentingnya membuat prompt yang spesifik. Prompt yang memiliki tujuan, kebutuhan, konteks, dan format output yang jelas dapat membantu AI menghasilkan hasil yang lebih sesuai.

### 2. Context sangat penting

AI membutuhkan konteks untuk memahami apa yang ingin dibuat atau dikerjakan. Prompt yang terlalu singkat dapat menghasilkan output yang kurang sesuai dengan kebutuhan.

### 3. Struktur Prompt

Struktur prompt yang dipelajari terdiri dari:

- Role
- Task
- Context
- Format

Struktur tersebut dapat digunakan untuk membuat instruksi kepada AI menjadi lebih jelas dan terarah.

### 4. Git dan GitHub memiliki fungsi yang berbeda

Git digunakan sebagai version control system untuk mengelola perubahan project, sedangkan GitHub digunakan sebagai platform online untuk menyimpan repository Git dan mendukung kolaborasi.

### 5. Memahami Git Workflow

Perubahan project dapat melalui beberapa tahap, yaitu:

**Working Directory → Staging Area → Commit → Repository**

Dengan memahami tahapan tersebut, perubahan dalam project dapat dikelola dengan lebih terstruktur.

### 6. Commit digunakan untuk menyimpan perubahan

Setelah perubahan dimasukkan ke staging area, perubahan dapat disimpan melalui commit menggunakan:

```bash
git commit -m "message"
```

### 7. Push digunakan untuk mengirim perubahan ke GitHub

Setelah melakukan commit, perubahan dapat dikirim ke repository GitHub menggunakan:

```bash
git push origin main
```

### 8. Pull digunakan untuk mengambil perubahan

Perubahan dari repository dapat diambil menggunakan:

```bash
git pull origin main
```

### 9. AI dan GitHub dapat digunakan bersama

AI dapat digunakan untuk membantu proses pembuatan project, sedangkan Git dan GitHub dapat digunakan untuk mengelola perubahan project dan menyimpan hasilnya secara online.

### 10. Pengetahuan Baru yang Diperoleh

Setelah mengikuti workshop, pengetahuan yang diperoleh meliputi:

- Dasar Prompt Engineering.
- Cara membuat prompt dengan struktur yang lebih baik.
- Pengertian Git.
- Pengertian GitHub.
- Perbedaan Git dan GitHub.
- Dasar Git Workflow.
- Penggunaan repository dan staging area.
- Penggunaan command Git dasar.
- Cara menghubungkan project dengan GitHub.
- Dasar penggunaan SSH untuk GitHub.
- Proses commit dan push project.
